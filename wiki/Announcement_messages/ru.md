# Объявления

![Уведомление об объявлении](img/notification.png "Уведомление об объявлении")

**Объявление** — это особый тип сообщений, предназначенный для массовой рассылки. В нем предусмотрены форматирование и больший лимит символов. К ключевым отличиям объявлений от обычных сообщений в чате можно отнести:

- Лимит в 1024 символа вместо 450
- Поддержка синтаксиса Markdown[^note-images] для форматирования текста
- Массовая рассылка
- Способность обходить настройку `игнорировать личные сообщения не от друзей`
- Возможность ответа на объявления только для тех пользователей, у которых есть права на их рассылку

## Требования

Отправка и возможность отвечать на объявления с помощью веб-сайта требует членства в [Команде Глобальной Модерации](/wiki/People/Global_Moderation_Team), [Команде Оценки Номинаций](/wiki/People/Nomination_Assessment_Team), или в [группе пользователей](/wiki/People/User_group) с правами отправки объявлений. Несмотря на это, только пользователи, состоящие в группе пользователей с правами отправки объявлений, могут их отправлять с помощью [osu! API v2](https://osu.ppy.sh/docs/index.html#create-channel).

### Подача заявки

Кто угодно может отправить заявку в группу с правами отправки объявлений с помощью подачи электронного письма на [accounts@ppy.sh](mailto:accounts@ppy.sh) с темой `Заявка на участие в группе рассылки объявлений`. Оно должно быть отправлено с адреса электронной почты, привязанного к вашему аккаунту osu!.

В содержание электронного письма должны входить:

- Имя пользователя отправителя в osu!
- Причина, по которой вам нужно право рассылать объявления, и как часто вы будете им пользоваться.

[Служба поддержки](/wiki/People/Account_support_team) рассмотрит вашу заявку и даст вам знать о своём решении.

## Отправка объявлений

Для отправки объявления откройте [страницу чата](https://osu.ppy.sh/community/chat) и нажмите на кнопку `создать объявление`. Укажите название канала, описание[^note-desc], список получателей и сообщение для рассылки. Наконец, нажмите кнопку `создать` для отправки объявления.

![Страница создания объявления](img/page.jpg "Страница создания объявления")

## Факты

- Объявления предназначены для прямой замены старых [форумных](/wiki/Community/Forum) сообщений.
- [Базовое внедрение](https://github.com/ppy/osu-web/pull/8418) системы объявлений произошло на веб-сайте 26 января 2022 года. Оно включало в себя появление группы отправки объявлений и возможность рассылки объявлений через API. Пользовательский интерфейс для отправки объявлений, вместе с выдачей модераторам прав на их рассылку, был [добавлен](https://github.com/ppy/osu-web/pull/8747) 1 июня 2022 года.
- ID группы рассылки объявлений — 47, она не имеет ни значка, ни отдельного цвета группы, а список её участников скрыт.

## Заметки

[^note-images]: В объявления нельзя вставлять изображения
[^note-desc]: В отличие от других полей для заполнения, описание необязательно.
