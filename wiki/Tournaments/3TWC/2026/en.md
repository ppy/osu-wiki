# 3 Digit Taiko World Cup 2026

![3TWC 2026 banner](img/banner.jpg)

The **3 Digit Taiko World Cup 2026** (***3TWC 2026***) is a worldwide 2v2 double-elimination osu!taiko tournament hosted by ::{ flag=CL }:: [Touche](https://osu.ppy.sh/users/1603962) and ::{ flag=CL }:: [ulko](https://osu.ppy.sh/users/1263669). It is the second instalment of the [3 Digit Taiko World Cup](/wiki/Tournaments/3TWC).

## Tournament schedule

| Event | Timestamp |
| --: | :-- |
| Registration phase | 2026-07-25/2026-09-20 |
| Screening phase | 2026-09-20/2026-09-27 |
| Qualifiers mappool showcase | 2026-09-27 16:00 (UTC) |
| Qualifiers | 2026-10-03/2026-10-04 |
| Round of 32 | 2026-10-10/2026-10-11 |
| Round of 16 | 2026-10-17/2026-10-18 |
| Quarterfinals | 2026-10-24/2026-10-25 |
| Semifinals[^semifinals-delay] | 2026-10-31/2026-11-08 |
| Finals | 2026-11-14/2026-11-15 |
| Grand Finals | 2026-11-21/2026-11-22 |
