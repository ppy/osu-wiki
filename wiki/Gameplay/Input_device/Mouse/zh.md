# 鼠标

**鼠标**是游玩 osu! 的热门方式，同时可以瞄准及点击。鼠标中键用来暂停游戏（可以在设置中停用），滚轮用来调整音量。

## 鼠标相关选项

### 鼠标灵敏度

这个选项可以让您自定义您的鼠标移动速度，预设为 1x。

### 鼠标原始输入 (Raw Input)

原始输入会绕过 Windows 内置的鼠标加速，并提供最准确的鼠标位置。在 Windows 7 及以上的版本中，必须启用原始输入才能自定义鼠标灵敏度。

### 开启光标边界

这个选项让光标只能在 osu! 的窗口中移动，默认为`只在全屏模式时`。可用的选项有：

- `从不`：不限制光标在 osu! 界面内。
- `只在全屏模式时`：只有开启全屏模式时才限制光标在 osu! 界面内。
- `总是`：总是限制光标在 osu! 界面内。

### 在游戏中禁用鼠标滚轮

在游戏中，你可以用鼠标滚轮控制音量以及暂停游戏。此选项将禁用这个功能。

### 在游戏中禁用鼠标按键

这个选项将在游戏过程中禁用所有的鼠标按键。为使用键盘点击的玩家设计。

### 点击波纹

点击时，光标周围出现一圈散开的波纹。
