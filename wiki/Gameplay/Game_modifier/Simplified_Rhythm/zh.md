# Simplified Rhythm（模组）

::: Infobox

<!-- lint ignore heading-increment -->

#### Simplified Rhythm

![Simplified Rhythm 模组图标](/wiki/Gameplay/Game_modifier_(lazer)/img/mods/SR.png)

*简化棘手的节奏！*

|  |  |
| :-- | :-- |
| 缩写 | SR |
| 类别 | 降低难度 |
| 默认快捷键 | `T` |
| 游戏模式 | ![][osu!taiko] |
| 得分系数 | `0.60x` |
| 状态 | 不计表现分 |
| 不兼容的模组 | 无 |

:::

::: alert-note
**注:** 对于 [lazer](/wiki/Client/Release_stream/Lazer) 模组的完整列表，请见：[游戏模组 (lazer)](/wiki/Gameplay/Game_modifier_(lazer))
:::

**Simplified Rhythm** 模组将复杂节奏（如 1/6）的排列替换为更简单的排列（如 1/4），以尝试降低 osu!taiko 的游戏难度。

## 自定义

![游戏客户端中的 Simplified Rhythm 自定义设置](/wiki/Gameplay/Game_modifier_(lazer)/img/customise/SR.png)

- `1/3 转换为 1/2 (1/3 to 1/2 conversion)` (默认禁用): 1/3 节奏的排列将被转换为 1/2 节奏。
- `1/6 转换为 1/4 (1/6 to 1/4 conversion)` (默认启用): 1/6 节奏的排列将被转换为 1/4 节奏。
- `1/8 转换为 1/4 (1/8 to 1/4 conversion)` (默认禁用): 1/8 节奏的排列将被转换为 1/4 节奏。
