# Synesthesia（模组）

::: Infobox

<!-- lint ignore heading-increment -->

#### Synesthesia

![Synesthesia 模组图标](/wiki/Gameplay/Game_modifier_(lazer)/img/mods/SY.png)

*按节奏给物件上色。*

|  |  |
| :-- | :-- |
| 缩写 | SY |
| 类别 | 娱乐 |
| 游戏模式 | ![][osu!] ![][osu!catch] |
| 得分系数 | `0.80x` |
| 状态 | 不计表现分 |
| 不兼容的模组 | 无 |

:::

::: alert-note
**注:** 对于 [lazer](/wiki/Client/Release_stream/Lazer) 模组的完整列表，请见：[游戏模组 (lazer)](/wiki/Gameplay/Game_modifier_(lazer))
:::

**Synesthesia** 模组会忽略[谱面](/wiki/Beatmap)的[连击色](/wiki/Beatmapping/Combo_colour)设置，将所有[打击物件](/wiki/Gameplay/Hit_object)按节奏设置颜色。为此，该模组会使用与[谱面编辑器](/wiki/Client/Beatmap_editor)中[音符时值](/wiki/Client/Beatmap_editor/Beat_snap_divisor)相同的颜色，即 1/2 时值的物件使用红色，1/4 时值的物件使用蓝色，等等。
