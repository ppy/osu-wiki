# No Release (mod)

::: Infobox

<!-- lint ignore heading-increment -->

#### No Release

![Ikon mod No Release](/wiki/Gameplay/Game_modifier_(lazer)/img/mods/NR.png)

*No more timing the end of hold notes.*

|  |  |
| :-- | :-- |
| Singkatan | NR |
| Tipe | Pengurang Kesulitan |
| Tombol pintasan default | `T` |
| Mode Permainan | ![][osu!mania] |
| Pengali Skor | `0.90x` |
| Status | Unranked |
| Mod yang tidak kompatibel | [Invert (IN)](/wiki/Gameplay/Game_modifier/Invert), [Hold Off (HO)](/wiki/Gameplay/Game_modifier/Hold_Off) |

:::

**Catatan:** Untuk melihat daftar keseluruhan dari semua mod [lazer](/wiki/Client/Release_stream/Lazer), kunjungi: [Game Modifier (lazer)](/wiki/Gameplay/Game_modifier_(lazer))

Mod **No Release** menghapus penalti [akurasi](/wiki/Gameplay/Accuracy) saat terlambat melepas tombol pada bagian ujung [hold note](/wiki/Beatmap/Pattern/osu!mania/Hold_note).

**Mod ini tidak dapat disesuaikan.**
