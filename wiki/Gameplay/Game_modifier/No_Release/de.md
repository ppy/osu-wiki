# No Release (Mod)

::: Infobox

<!-- lint ignore heading-increment -->

#### No Release

![No Release Modsymbol](/wiki/Gameplay/Game_modifier_(lazer)/img/mods/NR.png?1)

*Kein Timing am Ende von Hold-Notes mehr.*

|  |  |
| :-- | :-- |
| Akronym | NR |
| Typ | Verringerung der Schwierigkeit |
| Standard-Tastenkürzel | `T` |
| Spielmodi | ![][osu!mania] |
| Punktemultiplikator | `0,90x` |
| Status | Nicht gerankt |
| Inkompatible Mods | [Invert (IN)](/wiki/Gameplay/Game_modifier/Invert), [Hold Off (HO)](/wiki/Gameplay/Game_modifier/Hold_Off) |

:::

::: alert-note
**Anmerkung:** Für die vollständige Liste aller [lazer](/wiki/Client/Release_stream/Lazer)-Mods, siehe [Spielmodifikationen (lazer)](/wiki/Gameplay/Game_modifier_(lazer))
:::

Die Mod **No Release** entfernt die Verringerung der [Genauigkeit](/wiki/Gameplay/Accuracy) beim verspäteten Loslassen einer Taste am Ende einer [Hold-Note](/wiki/Gameplay/Hit_object/Hold_note).

**Diese Mod kann nicht personalisiert werden.**
