El mod **Dual Stages** añade un segundo campo de juego con el mismo número de teclas que el primero. Para pulsar las notas de este segundo campo de juego hay que usar un segundo sistema de controles. Los [mods de teclas](/wiki/Gameplay/Game_modifier/Key_mods_(lazer)) se pueden usar para modificar el número de teclas de ambos campos de juego (por ejemplo, si juegas un [beatmap](/wiki/Beatmap) de 4K con el mod de 7K y *Dual Stages*, el resultado será 7K + 7K).

*Ten en cuenta que este mod solo funciona con [converts](/wiki/Beatmap/Converts).*

**Este mod no se puede personalizar.**
