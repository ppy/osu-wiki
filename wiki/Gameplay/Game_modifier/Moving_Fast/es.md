# Moving Fast (mod)

::: Infobox

<!-- lint ignore heading-increment -->

El mod **Moving Fast** invierte la tecla de [dash](/wiki/Gameplay/Dash) del jugador. Por lo tanto, el jugador tiene que soltar la tecla para hacer un dash, ya que si la mantiene presionada, el catcher se moverá a velocidad normal.

**Este mod no se puede personalizar.**
