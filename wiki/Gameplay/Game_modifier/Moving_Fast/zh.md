# Moving Fast（模组）

::: Infobox

<!-- lint ignore heading-increment -->

#### Moving Fast

![Moving Fast 模组图标](/wiki/Gameplay/Game_modifier_(lazer)/img/mods/MF.png?1)

*一直冲也要慢一点！*

|  |  |
| :-- | :-- |
| 缩写 | MF |
| 类别 | Fun |
| 游戏模式 | ![][osu!catch] |
| 得分系数 | `1.00x` |
| 状态 | 不计入排名 |
| 不兼容的模组 | [Autoplay (AT)](/wiki/Gameplay/Game_modifier/Autoplay_(lazer)), [Cinema (CN)](/wiki/Gameplay/Game_modifier/Cinema_(lazer)), [Relax (RX)](/wiki/Gameplay/Game_modifier/Relax_(lazer)) |

::: alert-note

**Moving Fast** 模组会反转玩家的[冲刺](/wiki/Gameplay/Dash)按键状态。因此，玩家在加速时应松开按键，而按住按键时小人会以正常速度移动。

**该模组不支持自定义。**
