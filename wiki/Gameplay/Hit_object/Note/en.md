# Note

::: alert-note
**Note:** [Note (disambiguation)](/wiki/Disambiguation/Note).
:::

![osu!mania notes](/wiki/shared/Mania_notes.jpg "osu!mania notes")

**Notes** are the basic [hit objects](/wiki/Gameplay/Hit_object) of [osu!mania](/wiki/Game_mode/osu!mania) beatmaps. Each note moves in one [column](/wiki/Game_mode/osu!mania#playfield) of the playfield and has to be played with a single press of that column's key upon reaching the judgement line.

Community jargon calls the notes *rice*, as opposed to the *noodles* ([hold notes](/wiki/Gameplay/Hit_object/Hold_note)).

## Gameplay

Several notes can share the same timestamp as long as they occupy different columns. Such a group, called a [chord](/wiki/Beatmap/Pattern/osu!mania/Chord), has to be pressed at the same time. Notes may also appear while a hold note is still active in another column.

## Judgement

::: alert-note
**Main page:** [osu!mania judgement system](/wiki/Gameplay/Judgement/osu!mania)
:::

A note is judged based on a key press position within the note's timing window. The width of each of these hit windows is derived from the beatmap's [overall difficulty](/wiki/Beatmap/Overall_difficulty) (OD). Pressing the key before the MISS window opens does nothing, and a note that is never pressed is missed once its OK window has passed.

The timing window of the MAX judgement is constant in osu!(stable), but with the ScoreV2 mod enabled, as well as in osu!(lazer), it is affected by OD changes, which makes it more challenging to get a MAX starting from OD 8.1.

Every note that is hit adds a point to the [combo](/wiki/Gameplay/Combo_(score_multiplier)) counter and refills a small part of the [health bar](/wiki/Gameplay/Health), with better judgements recovering more. MEH and MISS judgements drain health instead.
