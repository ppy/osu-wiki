# Dash-Snapping

In [osu!catch](/wiki/Game_mode/osu!catch) können alle [Dashes](/wiki/Gameplay/Dash) und [Hyperdashes](/wiki/Gameplay/Hyperdash) in zwei Arten von Snappings eingeteilt werden — regulär gesnappt und höher gesnappt.

## Regulär gesnappt

Der Begriff **regulär gesnappt** bezeichnet [Dashes](/wiki/Gameplay/Dash) und [Hyperdashes](/wiki/Gameplay/Hyperdash), bei denen die Zeit zwischen den [aktiven Objekten](/wiki/Beatmapping/Active_object) mindestens doppelt so groß ist, wie die Zeit, die benötigt wird, um Dashes bzw. Hyperdashes zuzulassen. Zum Beispiel wird ein Hyperdash zwischen zwei Objekten im Schwierigkeitsgrad Platter, die 250 ms auseinander liegen, als regulär gesnappter Hyperdash bezeichnet.

## Höher gesnappt

Der Begriff **höher gesnappt** bezeichnet [Dashes](/wiki/Gameplay/Dash) und [Hyperdashes](/wiki/Gameplay/Hyperdash), die nicht die Bedingungen für regulär gesnappte Dashes erfüllen (d. h. die Zeit zwischen den Objekten ist geringer als die Schwelle, um als regulär eingestuft zu werden).

## Snapping-Referenztabelle

| Schwierigkeitsgrad | Regulär gesnappter Dash | Höher gesnappter Dash | Regulär gesnappter Hyperdash | Höher gesnappter Hyperdash |
| :-- | :-- | :-- | :-- | :-- |
| **Cup** | - | - | - | - |
| **Salad** | 250 ms oder mehr | 125 bis 249 ms | - | - |
| **Platter** | 125 ms oder mehr | 62 bis 124 ms | 250 ms oder mehr | 125 bis 249 ms |
| **Rain** | 125 ms oder mehr | 62 bis 124 ms | 125 ms oder mehr | 62 bis 124 ms |
| **Overdose** | - | - | - | - |
