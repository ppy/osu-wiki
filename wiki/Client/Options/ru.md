# Настройки

![Меню настроек](img/options_basic.jpg "Меню настроек (боковая панель слева)")

Чтобы открыть боковую панель с настройками osu!, кликните по кнопке `Options` в главном меню или нажмите `O` (сочетание `Ctrl` + `O` работает почти на любом экране). Для поиска нужной настройки достаточно ввести её название, когда панель открыта. Если ничего не нашлось, текст в поисковой строке задрожит.

Если значение настройки отличается от стандартного, серая вертикальная полоска слева от неё подсвечивается жёлтым. Кликните по полоске, чтобы вернуть значение по умолчанию.

## Общие

![Значок раздела «Общие»](img/general.jpg "Значок раздела «Общие»")

В этом разделе собраны настройки аккаунта, языка и обновлений игры.

### Вход

Если вы не залогинены, при запуске игры автоматически откроются настройки с предложением войти. Это можно пропустить: нажмите `Esc` или кнопку возврата, либо перейдите на экран выбора песни. В этом случае будет доступен только гостевой локальный аккаунт: вы не сможете загружать онлайн-рекорды, отправлять свои рекорды на сервер и играть в [мультиплеере](/wiki/Client/Interface/Multiplayer).

Пока вы не вошли в аккаунт, в разделе будут следующие настройки:

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Логин` | Ник для входа в аккаунт. | Текст | *(пусто)* |
| `Пароль` | Пароль для входа в аккаунт. | Пароль | *(пусто)* |
| `Запомнить логин` | Игра запомнит введённый ник. | Флажок | `Включено` |
| `Запомнить пароль` | Игра запомнит введённый пароль, и вход в аккаунт сохранится между запусками. | Флажок | `Отключено` |
| `Вход` | Войти в аккаунт с указанными ником и паролем. Вместо этого можно нажать `Enter` в поле ника или пароля. | Кнопка |  |
| `Зарегистрироваться` | Открыть экран [регистрации аккаунта](/wiki/Registration). | Кнопка |  |

---

Если вы уже вошли в аккаунт, в разделе будет только одна кнопка:

| Название | Описание | Тип |
| :-- | :-- | :-- |
| `Logged in as {username}` | Открыть меню пользователя (см. ниже). | Кнопка |

---

Если нажать на `Logged in as {username}`, появится меню со следующими кнопками:

| Название | Описание | Тип |
| :-- | :-- | :-- |
| `1. Открыть профиль` | Открыть ваш профиль на сайте. | Кнопка |
| `2. Выйти` | Выйти из аккаунта. | Кнопка |
| `3. Поменять аватарку` | Открыть на сайте страницу, на которой можно сменить аватарку. | Кнопка |
| `4. Отмена` | Закрыть меню (вместо этого можно нажать `Esc`). | Кнопка |

Это же меню открывается, если кликнуть по своей карточке игрока (там, где она есть).

## Графика

![Значок раздела «Графика»](img/graphics.jpg "Значок раздела «Графика»")

Этот раздел посвящён внешнему виду игры, отдельным элементам интерфейса и настройкам изображения.

### Обработчик графики

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Ограничение FPS` | Ограничить частоту кадров (подробнее см. ниже). | Выпадающий список | `Optimal` |
| `Счётчик FPS` | Показывать счётчик FPS в правом нижнем углу экрана. | Флажок | `Отключено` |
| `Режим совместимости` | Использовать прежний обработчик графики, рассчитанный на старые компьютеры. При смене настройки игра перезапустится. | Флажок | `Отключено` |
| `Снизить кол-во потерянных кадров` | Поменять настройки графики так, чтобы кадры реже пропускались, а изображение не дёргалось. | Флажок | `Отключено` |
| `Обнаруживать снижение производительности` | Предупреждать, если какая-то программа на компьютере может замедлять работу игры. | Флажок | `Включено` |

---

::: alert-notice
**Примечание:** когда окно игры неактивно, частота кадров автоматически ограничивается 30 FPS.
:::

*Владельцам ноутбуков: с вариантом `Нет (во время игры)` ноутбук может перегреться!*

В списке `Ограничение FPS` доступны следующие варианты:

| Название | Описание |
| :-- | :-- |
| `Вертикальная синхронизация` | Ограничить частоту кадров частотой обновления монитора (подробнее см. ниже). |
| `Power Saving` | Ограничить частоту кадров удвоенной частотой обновления монитора. |
| `Optimal` | Ограничить частоту кадров восьмикратной частотой обновления монитора, но не выше 960 FPS. |
| `Нет (во время игры)` | Ограничить частоту кадров частотой обновления монитора (подробнее см. ниже). |

- `Вертикальная синхронизация`: говоря простым языком, игра ждёт, пока кадр полностью отрисуется, и только потом выводит его на экран.
  - Этот вариант стоит выбрать, если вы замечаете разрывы изображения (когда нижняя часть картинки отстаёт от верхней).
  - С другой стороны, игре приходится ждать отрисовки каждого кадра, из-за чего могут появиться задержки и замедление.
- `Нет (во время игры)`: ограничение снимается только во время прохождения карты.
  - Вне игры частота кадров ограничена удвоенной частотой обновления монитора или 240 FPS, в зависимости от того, что больше.
  - Этот вариант **не рекомендуется**: с ним изображение может дёргаться.
  - Если выбрать вместо него `Optimal`, разница в общей задержке (от нажатия до вывода на экран) будет практически незаметна.

### Параметры экрана

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Разрешение` | Настроить разрешение игры. В списке есть только разрешения, которые поддерживаются вашим монитором и видеокартой. | Выпадающий список |  |
| `Полноэкранный режим` | Развернуть игру на весь экран (обычно это снижает задержку ввода). | Флажок | `Включено` |
| `Render at native resolution` | Использовать «родное» разрешение монитора, но показывать osu! в уменьшенной области по центру экрана. | Флажок | `Включено` |
| `Minimise on alt-tab during fullscreen` | Сворачивать окно игры при нажатии `Alt` + `Tab`. | Флажок | `Включено` |
| `По горизонтали` | Сдвинуть изображение по горизонтали в режиме леттербоксинга. Доступно, только если включена настройка `Render at native resolution`. | Слайдер | `0%` |
| `По вертикали` | Сдвинуть изображение по вертикали в режиме леттербоксинга. Доступно, только если включена настройка `Render at native resolution`. | Слайдер | `0%` |

- Если `Полноэкранный режим` выключен, под ним появится предупреждение `Оконный режим увеличивает задержку ввода!`.

| Название | Описание |

### Отладка

#### Версия сборки

Здесь показана текущая версия сборки и ветка, из которой игра получает обновления. Если кликнуть по версии, в браузере откроется список изменений.

Номер версии записывается в следующем формате:

```
b{YYYY}{MM}{DD}.{revision}{type}
```

- `{YYYY}`: год сборки.
- `{MM}`: месяц сборки.
- `{DD}`: день сборки.
- `{revision}`: номер ревизии сборки.
  - Если ревизии нет, точка не пишется.
- `{type}`: тип сборки.
  - Если тип не указан, то это `Стабильная` ветка.

## Факты

- Если ввести ник, но оставить поле для пароля пустым, osu! будет подписывать этим ником локальные рекорды.
- При открытии панели настроек автоматически срабатывает кнопка `У Вас последняя версия osu!`, то есть игра начинает проверять обновления.
- Настройка `Seasonal backgrounds` появилась после положительных отзывов в адрес команды разработчиков.
  - Подробнее: [изменения фона главного меню](https://osu.ppy.sh/community/forums/topics/606931)
