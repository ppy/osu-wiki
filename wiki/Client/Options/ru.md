# Настройки

![Меню настроек](img/options_basic.jpg "Меню настроек (боковая панель слева)")

В главном меню нажмите `Options` или клавишу `O` (либо `Ctrl` + `O`, которая работает практически на любом экране), чтобы открыть боковую панель настроек и изменить доступные настройки osu! После открытия меню настроек можно начать вводить текст для поиска определённого параметра. Если поиск не дал результатов, текст в строке поиска начнёт дрожать.

Когда изменяется настройка, имеющая значение по умолчанию, серая вертикальная полоса слева от неё загорится жёлтым. Нажатие на неё сбросит значение до значения по умолчанию.

## Общие

![Значок раздела «Общие»](img/general.jpg "Значок раздела «Общие»")

Этот раздел посвящён аккаунту, языковым настройкам и обновлениям osu!.

### Вход

Если вы не вошли в аккаунт в игровом клиенте, при запуске автоматически откроется меню настроек с предложением войти. Его можно проигнорировать, нажав `Esc`, кнопку возврата или перейдя на экран выбора песни. Если не входить в аккаунт, игровой клиент пометит вас как «Гость», и вы не сможете получать онлайн-результаты, отправлять результаты или играть в [мультиплеер](/wiki/Client/Interface/Multiplayer).

Если вы являетесь гостем, будут показаны следующие настройки:

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Логин` | Поле для ввода имени пользователя при входе. | Текст | *(пусто)* |
| `Пароль` | Поле для ввода пароля при входе. | Пароль | *(пусто)* |
| `Запомнить логин` | Если включено, игровой клиент запомнит введённое имя пользователя. | Флажок | `Enabled` |
| `Запомнить пароль` | Если включено, игровой клиент запомнит введённый пароль. Это также сохранит вход в аккаунт в игровом клиенте. | Флажок | `Disabled` |
| `Вход` | Войти в osu! с указанными учётными данными. Также можно нажать `Enter` в поле имени пользователя или пароля. | Кнопка |  |
| `Зарегистрироваться` | Открывает экран [регистрации аккаунта](/wiki/Registration). | Кнопка |  |

---

Если вы вошли в аккаунт, вы увидите:

| Название | Описание | Тип |
| :-- | :-- | :-- |
| `Logged in as {username}` | Открывает меню пользователя, описанное ниже. | Кнопка |

---

Если нажать на `Logged in as {username}`, появится меню со следующими кнопками:

| Название | Описание | Тип |
| :-- | :-- | :-- |
| `1. Открыть профиль` | Открывает ваш профиль на сайте. | Кнопка |
| `2. Выйти` | Выполняет выход из аккаунта в игровом клиенте. | Кнопка |
| `3. Поменять аватарку` | Позволяет изменить изображение профиля (после этого вы будете перенаправлены на сайт). | Кнопка |
| `4. Отмена` | Закрывает это окно. Также можно нажать `Esc`. | Кнопка |

Это меню также можно открыть, нажав на свою карточку игрока там, где она доступна.

## Графика

![Значок раздела «Графика»](img/graphics.jpg "Значок раздела «Графика»")

Этот раздел посвящён внешнему виду игрового клиента, некоторым элементам интерфейса и настройкам изображения.

### Обработчик графики

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Ограничение FPS` | Устанавливает ограничение частоты кадров. Подробнее см. ниже. | Выпадающий список | `Optimal` |
| `Счётчик FPS` | Включает или отключает счётчик FPS. Он отображается в правом нижнем углу экрана. | Флажок | `Отключено` |
| `Режим совместимости` | Использует старый рендерер, который osu! применяла для старых компьютеров. После изменения игровой клиент будет перезапущен. | Флажок | `Отключено` |
| `Снизить кол-во потерянных кадров` | Изменяет графические настройки для уменьшения количества пропущенных кадров и рывков изображения. | Флажок | `Отключено` |
| `Обнаруживать снижение производительности` | Предупреждает, если другая программа на компьютере может ухудшать производительность игрового клиента. | Флажок | `Включено` |

---

::: alert-notice
**Примечание:** когда игровой клиент не является активным окном, ограничение FPS автоматически снижается до 30 FPS.
:::

*Внимание пользователям ноутбуков: использование `Нет (во время игры)` может привести к перегреву ноутбука!*

При открытии выпадающего списка `Ограничение FPS` будут доступны следующие варианты:

| Название | Описание |
| :-- | :-- |
| `Вертикальная синхронизация` | Ограничивает частоту кадров частотой обновления монитора. Подробнее см. объяснение ниже. |
| `Power Saving` | Ограничивает частоту кадров двумя частотами обновления монитора. |
| `Optimal` | Ограничивает частоту кадров восемью частотами обновления монитора, но не более чем 960 FPS. |
| `Нет (во время игры)` | Ограничивает частоту кадров частотой обновления монитора. Подробнее см. объяснение ниже. |

- Объяснение `Вертикальная синхронизация`: если объяснять простыми словами, VSync заставляет игру дождаться полной отрисовки кадра перед его отображением.
  - Эту настройку стоит использовать, если вы замечаете «разрыв изображения» (когда нижняя часть изображения отстаёт от верхней).
  - Несмотря на сказанное выше, это может привести к задержкам или замедлению, поскольку игровой клиент должен ждать отрисовки каждого кадра.
- Объяснение `Нет (во время игры)`: Unlimited действует только во время игры на карте.
  - Когда карта не запущена, частота кадров ограничивается удвоенной частотой обновления монитора или 240 FPS — в зависимости от того, какое значение выше.
  - Эта настройка **не рекомендуется**. Использование `Нет (во время игры)` может привести к рывкам изображения.
  - Использование `Optimal` вместо неё практически не даёт заметной разницы в задержке системы (от ввода до вывода) по сравнению с `Нет (во время игры)`.

### Параметры экрана

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |
| `Разрешение` | Устанавливает разрешение игрового клиента. Доступные разрешения ограничены теми, которые поддерживаются вашим монитором и видеокартой. | Выпадающий список |  |
| `Полноэкранный режим` | Запускает игровой клиент в полноэкранном режиме (обычно это уменьшает задержку ввода). | Флажок | `Включено` |
| `Render at native resolution` | Использует полное нативное разрешение, но отображает osu! в меньшей области по центру экрана. | Флажок | `Включено` |
| `Minimise on alt-tab during fullscreen` | Сворачивает главное окно при нажатии `Alt` + `Tab`. | Флажок | `Включено` |
| `По горизонтали` | Настраивает горизонтальное смещение в режиме Letterboxing. Отображается только при включённой настройке `Render at native resolution`. | Ползунок | `0%` |
| `По вертикали` | Настраивает вертикальное смещение в режиме Letterboxing. Отображается только при включённой настройке `Render at native resolution`. | Ползунок | `0%` |

- Если `Полноэкранный режим` отключён, под ним появится надпись `Оконный режим увеличивает задержку ввода!`.

### Главное меню

| Название | Описание | Тип | По умолчанию |
| :-- | :-- | :-- | :-- |

| `Параллакс` | Добавляет небольшой эффект параллакса при перемещении по внутриигровым меню (не во время игры). | Флажок | `Включено` |

---

При открытии выпадающего списка `Seasonal backgrounds` будут доступны следующие варианты:

| Название | Описание |
| :-- | :-- |
| `Sometimes` | Сезонные фоны будут отображаться в течение нескольких недель в начале каждого сезона. Команда osu!dev сама определяет, когда их убрать и заменить более обычными фонами. |
| `Never` | Сезонные фоны никогда не будут отображаться, а во всех случаях будут использоваться стандартные. |
| `Always` | Всегда будет использоваться фон текущего сезона. |

---

При открытии выпадающего списка `Прогресс` будут доступны следующие варианты:

| Название | Описание |
| :-- | :-- |
| `Справа вверху (круг)` | Использует круговую диаграмму для отображения оставшегося времени до начала песни и времени до её завершения. Отображается слева от показателя точности. |
| `Справа вверху (полоса)` | Использует короткую горизонтальную полосу для отображения оставшегося времени до завершения песни. Располагается под счётом, но над показателем точности. |
| `Справа внизу` | Использует короткую горизонтальную полосу для отображения оставшегося времени до завершения песни. Располагается в правом нижнем углу. |
| `Внизу (полоса)` | Использует длинную горизонтальную полосу для отображения оставшегося времени до завершения песни. Располагается в нижней части экрана. |

---

При открытии выпадающего списка `Шкала точности` будут доступны следующие варианты:

| Название | Описание |
| :-- | :-- |
| `Отключена` | Не использовать индикатор для отображения тайминга попаданий игрока. |
| `Цветовая` | Использовать цветные блоки для отображения тайминга попаданий. (osu!catch всегда использует этот вариант, если выбран `Отклонение от нуля`.) |
| `Отклонение от нуля` | Использовать индикатор для отображения тайминга попаданий. Он показывает, было ли нажатие слишком ранним или слишком поздним. |

### Отладка

#### Версия сборки

Показывает текущую версию сборки игрового клиента и тип сборки, обновления которой получает игровой клиент. При нажатии на эту информацию в предпочитаемом браузере откроются примечания к выпуску.

Версии сборок записываются в следующем формате:

```
b{YYYY}{MM}{DD}.{revision}{type}
```

- `{YYYY}` — год сборки.
- `{MM}` — месяц сборки.
- `{DD}` — день сборки.
- `{revision}` — номер ревизии сборки.
  - Если номер ревизии отсутствует, десятичная точка удаляется.
- `{type}` — тип сборки.
  - Если значение типа сборки отсутствует, подразумевается `Стабильная`.

## Интересные факты

- Если ввести имя пользователя, но оставить поле пароля пустым, osu! будет использовать это имя при локальном сохранении результата.
- Открытие боковой панели настроек автоматически запускает функцию `У Вас последняя версия osu!` (начинается проверка наличия обновлений).
- Настройка `Seasonal backgrounds` была добавлена после положительных отзывов в адрес команды osu!dev.
  - Подробнее: [изменения фона главного меню](https://osu.ppy.sh/community/forums/topics/606931)

### История

- Старый экран настроек был отдельным экраном с вкладками, кнопками и тёмно-голубым фоном.
- На старом экране настроек также был экран выбора скина, позволявший предварительно просматривать игровой процесс карты в osu!.
  - После переноса настроек в боковую панель этот экран всё ещё можно было открыть, выбрав файл скина.
  - Позднее доступ к нему был удалён после появления предварительного просмотра скинов и функции предварительного просмотра игрового процесса.
