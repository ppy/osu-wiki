# Skróty klawiszowe

W osu! jest wiele różnych skrótów klawiszowych, których można używać zarówno w grze, jak i w menu. Są one wymienione poniżej wraz z ich funkcjami.

::: alert-notice
Ten artykuł zawiera domyślne skróty klawiszowe. Niektóre z nich można zmienić w [opcjach](/wiki/Client/Options).
:::

## Cała gra

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `Alt` + `F4` | Natychmiast zamyka klienta gry. Jeżeli jesteś w trakcie rozgrywki lub w edytorze, cofa do ekranu wyboru piosenki. Jeżeli znajdujesz się w osu!direct, cofa do menu głównego. |
| `Alt` + `Strzałka w górę/dół` | Zmienia ogólną głośność. Użyj strzałki w lewo/prawo, aby zmienić głośność efektów lub muzyki. |
| `Ctrl` + `Alt` + `Shift` + `S` | Odświeża obecnie wybraną skórkę. Jeżeli zostanie użyty w czasie rozgrywki lub w ekranie wyniku, odświeży ją od razu po powrocie do ekranu wyboru piosenki. |
| `Ctrl` + `F11` | Przełącza wyświetlanie wykresu opóźnienia. Naciśnięcie `Ctrl` w czasie, gdy wykres jest aktywny zatrzyma go. |
| `F7` | Zmienia limit klatek. |
| `F8` | Przełącza okno czatu. |
| `F9` | Przełącza rozszerzone okno czatu. |
| `F10` | Włącza/wyłącza wszystkie przyciski myszy podczas gry (z wyjątkiem kółka myszy, którego nie można wyłączyć). |
| `F12` | Robi zrzut ekranu. Kliknij na powiadomienie, aby otworzyć folder `Screenshots`. |
| `Shift` + `F12` | Robi zrzut ekranu i wysyła go na serwer, a następnie otwiera go w przeglądarce. Zrzut ekranu zostanie zapisany również na komputerze. |
| `Insert` | Tak zwany [boss key](https://en.wikipedia.org/wiki/Boss_key). Minimalizuje klienta gry do obszaru powiadomień i wycisza go. |
| `Shift` + `F1` | Otwiera [osu!status](https://twitter.com/osustatus) w przeglądarce (działa jedynie w przypadku błędów z połączeniem). |
| `Ctrl` + `O` | Otwiera opcje. [Kalibratora opóźnienia](/wiki/Client/Options/Offset_Wizard) nie można uruchomić poza głównym menu. |

## Menu główne

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `Alt` + `Enter` | Przełącza tryb pełnoekranowy. |
| `Up/Down Arrow` | Zmienia ogólną głośność. Użyj strzałki w lewo/prawo, aby zmienić głośność efektów lub muzyki. |
| `Esc` | Cofa lub anuluje wybór. |
| `P`, `E` lub `O` | Otwiera menu gry. |
| trzy razy `P`  | Otwiera tryb jednoosobowy. |
| dwa razy `P`, a następnie `M` | Otwiera [tryb wieloosobowy](/wiki/Client/Interface/Multiplayer). |
| dwa razy `E` | Otwiera edytor. |
| `O` | Otwiera opcje. |
| `Q` | Zamyka grę po potwierdzeniu. |
| `Esc` | Zamyka grę po potwierdzeniu (gdy opcje i menu gry są zamknięte). |
| `F` | Przełącza wyświetlanie licznika FPS |

### Odtwarzacz muzyki

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `Z` lub `F1` | Odtwarza poprzedni utwór. |
| `X` lub `F2` | Odtwarza utwór. Jeśli utwór jest już odtwarzany, cofa go do początku. |
| `C` | Pauzuje lub odpauzowuje. |
| `F4` | Zatrzymuje muzykę i cofa bieżący utwór do początku. |
| `V` lub `F5` | Odtwarza następny utwór. |
| `J` lub `F6` | Otwiera menu "przejdź do". |
| `R` | Odtwarza losowy utwór. |

| `Ctrl` + `1` | Zmienia tryb gry na [osu!](/wiki/Game_mode/osu!). |
| `Ctrl` + `2` | Zmienia tryb gry na [osu!taiko](/wiki/Game_mode/osu!taiko). |
| `Ctrl` + `3` | Zmienia tryb gry na [osu!catch](/wiki/Game_mode/osu!catch). |
| `Ctrl` + `4` | Zmienia tryb gry na [osu!mania](/wiki/Game_mode/osu!mania). |
| `Ctrl` + `Enter` | Włącza wybraną mapę z [modem Auto](/wiki/Gameplay/Game_modifier/Auto). |
| `Ctrl` + `Shift` + `Enter` | Włącza wybraną mapę z [modem Cinema](/wiki/Gameplay/Game_modifier/Cinema). |
| `Ctrl` + `A` | Włącza/wyłącza mod Auto. |
| `Ctrl` + `F3` lub `Ctrl` + `+` | Zwiększa szybkość przewijania (tylko w trybie osu!mania). |
| `Ctrl` + `F4` lub `Ctrl` + `-` | Zmniejsza szybkość przewijania (tylko w trybie osu!mania). |
| `Ctrl` + `Backspace` | Kasuje ostatnie słowo w wyszukiwarce. |
| `Strzałka w górę/dół` | Wybiera poziom trudności znajdujący się wyżej/niżej. |
| `Strzałka w lewo/prawo` | Wybiera beatmapę znajdującą się wyżej/niżej. |
| `Page Up/Down` | Przewija listę beatmap w górę/dół. |
| `Enter` | Zatwierdza wybór (podczas wybierania opcji lub zarządzania kolekcjami) lub włącza wybrany poziom trudności (podczas wyboru beatmapy). |
| `Shift` + `Strzałka w lewo/prawo` | Przełącza pomiędzy kolekcjami. |
| `Shift` + `Enter` | Rozwija/zwija kolekcję. |

## Rozgrywka

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `+` lub `-` | Zmienia opóźnienie lokalne (przytrzymaj `Alt`, aby zmienić precyzję). |
| `Esc` | Pauzuje rozgrywkę. W przypadku wybrania moda Auto lub Cinema, cofa do menu wyboru piosenki. |
| `Spacja` | Pomija wstęp. |
| `Tab` | Przełącza wyświetlanie tabeli wyników. |
| `Shift` + `Tab` | Przełącza wyświetlanie interfejsu. |
| `H` | Przełącza wyświetlanie tabeli wyników podczas oglądania powtórki lub obserwowania innego gracza. |
| `F3` lub `F4` | Zmienia szybkość przewijania w trybie osu!mania (można użyć na chwilę przed rozpoczęciem gry). |
| `Ctrl` + `R` lub `` ` `` | Wymaga przytrzymania dłużej. Szybki restart mapy (automatycznie pomija wstęp). |

### Ogólne

Te skróty klawiszowe działają w każdym miejscu edytora.

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `Z` | Przeskakuje do początku utworu lub do pierwszego obiektu mapy. |
| `V` | Przeskakuje do końca utworu lub do ostatniego obiektu mapy. |
| `X` | Odtwarza od początku. |
| `C` lub `Spacja` | Pauzuje/wznawia odtwarzanie. |
| `Strzałka w lewo` lub `Strzałka w prawo` | Przewija utwór. |
| `Strzałka w górę` lub `Strzałka w dół` | Przeskakuje do poprzedniej/kolejnej sekcji czasowej. |
| `Shift` + `Strzałka w lewo` lub `Shift` + `Strzałka w prawo` | Przewija utwór z czterokrotną szybkością. |
| `Ctrl` + `B` | Dodaje zakładkę w bieżącym momencie. |
| `Ctrl` + `Shift` + `B` | Usuwa zakładkę znajdującą się w bieżącym momencie. |
| `Ctrl` + `Strzałka w lewo/prawo` | Przeskakuje do poprzedniej/następnej zakładki. |
| `Ctrl` + `L` | Powrót do poprzedniego zapisu (częściowy). Spowoduje to ponowne załadowanie plików `.osu` oraz `.osb`. |
| `Ctrl` + `Shift` + `L` | Powrót do poprzedniego zapisu (całkowity). Spowoduje to ponowne załadowanie wszystkich plików beatmapy. |
| `Ctrl` + `O` | Otwiera okno wyboru poziomu trudności. |
| `Ctrl` + `S` | Zapisuje beatmapę. |
| `Ctrl` + `N` | Po potwierdzeniu usuwa wszystkie obiekty. |
| `Ctrl` + `Strzałka w górę/dół` | Zmienia szybkość odtwarzania o 25%. |
| `Ctrl` + `Shift` + `Strzałka w górę/dół` | Zmienia szybkość odtwarzania o 5%. |
| `F1` | Otwiera tryb [kompozycji](/wiki/Client/Beatmap_editor/Compose) (zakładka `Compose`). |
| `F2` | Otwiera [edytor storyboardu](/wiki/Client/Beatmap_editor/Design) (zakładka `Design`). |
| `F3` | Otwiera tryb [timingu](/wiki/Client/Beatmap_editor/Timing) (zakładka `Timing`). |
| `F4` | Otwiera [ustawienia beatmapy](/wiki/Client/Beatmap_editor/Song_setup) (zakładka `Song Setup`). |
| `F5` | Włącza tryb testowania mapy. |
| `F6` | Otwiera panel sekcji czasowych. |
| `Ctrl` + `P` | Dodaje dziedziczącą sekcję czasową w bieżącym momencie. Otworzy również panel sekcji czasowych, jeśli zostanie użyty poza trybem timingu. |
| `Ctrl` + `Shift` + `P` | Dodaje niedziedziczącą sekcję czasową w bieżącym momencie. Otworzy również panel sekcji czasowych, jeśli zostanie użyty poza trybem timingu. |
| `Ctrl` + `I` | Usuwa obecną sekcję czasową. Nie zadziała w przypadku pierwszej niedziedziczącej sekcji czasowej. |

#### Myszka

| :-- | :-- |
| `Kółko myszy` | Przewija piosenkę. |

### Timing

| Skrót klawiszowy | Funkcja |
| :-- | :-- |
| `T` | Naciskaj w rytm piosenki, aby automatycznie ustawić tempo. |
| `Shift` podczas zmiany BPM lub opóźnienia | Zwiększa o wartość pięciokrotnie większą niż zwykle. |
| `Ctrl` podczas zmiany BPM | Zmienia wartość o 0.25. |
| `Ctrl` podczas zmiany opóźnienia | Zmienia wartość o 1. |
| `Ctrl` podczas zmiany prędkości slidera | Zmienia wartość o 0.1. |
